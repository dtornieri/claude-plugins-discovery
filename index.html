Claude Discovery

Painel autocontido para navegar os 203 plugins oficiais do Claude Code, o catálogo público de servidores MCP e o mapa das suas próprias conversas a partir do export oficial. Tudo processado no seu navegador — nada sobe para servidor. Plugins e MCPs são públicos; os chats vêm do seu export local.

🔒
Privacidade primeiro. Este HTML é estático e não tem dados pessoais embutidos. Quando você carrega seu export, o arquivo é processado localmente pelo JavaScript do navegador — não há upload para nenhum servidor, nem mesmo o que hospeda esta página. Opcionalmente o painel pode salvar uma cópia no localStorage do seu navegador para próximas visitas; você pode limpar isso a qualquer momento no botão da barra lateral.

📥 Como obter seu export oficial do Claude
1
Acesse claude.ai autenticado e abra Settings → Privacy → Export data.Disponível em qualquer plano (Free, Pro, Max, Team, Enterprise).
2
Clique em "Export data". A Anthropic enviará um e-mail para o endereço cadastrado quando o ZIP estiver pronto.Tempo típico: alguns minutos a algumas horas, dependendo do volume.
3
Baixe o ZIP do link no e-mail e descompacte. Você verá esta estrutura:
conversations.json (chats fora de Projects) · projects/ (pasta com cada Project) · memories.json (memórias salvas pelo Claude) · users.json (seu perfil).Para aproveitar tudo, selecione a pasta inteira descompactada no painel. Para subir apenas as conversas avulsas, basta o conversations.json.
4
Volte aqui e carregue. Tudo daí pra frente é offline — pode desconectar a internet depois do upload e o painel continua funcionando.Para atualizar com chats novos: refaça o export periodicamente e recarregue.
🤔 Por que não atualiza sozinho?
A Anthropic não expõe API pública para terceiros listarem chats de usuários. Não existe um fluxo OAuth do tipo "autorize esta página a ler seus chats" — é proposital, faz parte do modelo de privacidade da plataforma. O único canal legítimo de extração é o export que você mesmo solicita. Por consequência, qualquer painel que pretenda mostrar seus dados precisa ou rodar como extensão de navegador autenticada na sua sessão (alto custo de manutenção, distribuição via Chrome Web Store), ou ler um arquivo que você forneceu — que é o caminho deste painel. Para hospedar e enviar a outras pessoas, basta servir esse HTML em qualquer lugar (GitHub Pages, Cloudflare Pages, S3, sua VPS) — cada visitante carrega o próprio export.
